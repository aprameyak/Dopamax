## About

Admin dashboard for Dopamax built with Next.js and TypeScript, deployed on Vercel. Includes Home, Support, and Privacy pages for managing app settings and user support.

## Features

- Fast, SEO-friendly Next.js app  
- Type-safe with TypeScript  
- Pages: Home, Support, Privacy  
- Deployed and optimized for Vercel
