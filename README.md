## About

**Dopamax** is a productivity-focused task management app built with **React Native**, **Expo**, and **TypeScript** that uses local **SQLite** storage to keep your to-do list fast and fully offline. It's designed around quick task entry and lightweight progress tracking to help you stay on top of your day without friction.

## Features

- Quick task creation and inline editing
- Task completion tracking with progress indicators
- Fully offline local data persistence using Expo SQLite
- Cross-platform support for Android and iOS via Expo
- Minimal, distraction-free UI optimized for fast task management

## Technology Stack

- **Mobile**: React Native, Expo, TypeScript
- **Storage**: SQLite (expo-sqlite)
