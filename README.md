## About

Dopamax is a React Native Expo app built with TypeScript and SQLite designed to help users boost productivity. It’s a fast, easy-to-use todo list that lets you quickly jot down tasks, track progress, and stay motivated.

## Features

- Quick task creation and editing  
- Tracks task progress and completion  
- Local data storage with SQLite  
- Clean, minimal UI for fast task management  
- Cross-platform: Android & iOS (via Expo)
