## About

**DopamaxAdmin** is the companion web application for the Dopamax iOS app — a productivity app that turns tasks into dopamine hits. Built with **Next.js** and **TypeScript**, it serves as the public-facing website with a landing page, support center, and privacy policy for App Store compliance.

## Features

- Landing page introducing Dopamax with gradient branding and navigation
- Support page with contact information and help resources
- Privacy policy page for App Store compliance
- Vercel Analytics integration for traffic monitoring

## Technology Stack

- **Frontend**: Next.js, React, TypeScript
